# CertGuard-PA Branding

## Primary logo

The approved CertGuard-PA project logo is a premium chrome/silver cybersecurity mark built around:

- shield emblem
- certificate/document motif
- validation checkmark or seal
- subtle circuit/automation accents
- `CertGuard-PA` wordmark
- dark charcoal/black background
- silver/chrome metallic treatment with soft blue-white highlights

Canonical asset path:

```text
docs/assets/certguard-pa-logo.png
```

## Usage

Use the primary logo for:

- README header
- documentation covers
- splash screens
- project presentations
- release notes

Use the derived icon-only artwork for:

- Windows application icon
- taskbar icon
- installer icon
- service/tool branding

## Protected rules

Do not replace the logo with a flat generic icon without explicit approval.

Do not include third-party vendor logos or trademarks inside the CertGuard-PA logo.

Do not change the brand direction away from the current premium enterprise cybersecurity style.

Keep future logo/icon assets visually consistent with the current approved concept:

```text
Premium chrome/silver shield + certificate + checkmark + digital/circuit cues.
```

## Asset notes

Preferred project asset names:

```text
assets/certguard-pa.ico
```

If the logo is regenerated, preserve the same visual language and update this document with the new approved asset path.
